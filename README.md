# GitHub Pages Deployment using GitHub Actions

This project demonstrates a simple CI/CD pipeline using GitHub Actions.

## What it does
- Deploys a static HTML website to GitHub Pages
- Runs automatically when `index.html` is changed
- Uses GitHub Actions for deployment
